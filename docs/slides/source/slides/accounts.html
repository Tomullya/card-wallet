Счета · BR-ACC

Открыть счёт и посмотреть баланс

POST

/accounts

currency — обязательно: EUR, USD или PLN заглавными. Ответ 201, баланс "0.00"

GET

/accounts

Только свои счета, по дате создания. Параметров нет

GET

/accounts/{id}

Один счёт с балансом. Чужой или несуществующий → 404

409 ACCOUNT_ALREADY_EXISTS

Второй счёт в той же валюте. Один счёт на валюту — проще клиенту и контролю баланса; защищено и в базе.

422 VALIDATION_ERROR

GBP, "eur" маленькими, пустое значение, id не в формате UUID.

Card Wallet API · 08

Ограничение «один счёт на валюту» закреплено уникальным ключом user_id + currency в базе, поэтому оно соблюдается даже при одновременных запросах.
