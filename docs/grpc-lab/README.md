## Как устроен урок

1. **Зачем** — простыми словами, на примере платежей.
2. **Попробуй в Postman** — пошагово. Названия кнопок в твоей версии Postman могут немного
   отличаться — ищи похожие.
3. **Посмотри в коде** — короткий пример на Python.
4. **Задание** — допиши тесты в `grpc-lab/exercises/test_lab_0N_*.py` и проверь:
   ```bash
   .venv/bin/python scripts/grpc_lab_check.py N
   ```
   ✅ — тест прошёл, ❌ — что пошло не так. «← ещё не написан» значит, что там ещё стоит `TODO`.
5. **Вопросы с собеседования** — ответь вслух, ответы в конце урока.

## Решения

`grpc-lab/solutions/` — эталонные решения. Открывай **после** своей попытки, чтобы сравнить.
`grpc-lab/lab.py` — помощники для заданий: ключи `WALLET` и `MONITOR`, функция `payment()`,
класс `Watch` для потока событий.

## Шпаргалка ключей

| Ключ (`x-api-key`) | Роль | Что можно |
|---|---|---|
| `dev-wallet-key` | кошелёк | всё |
| `dev-monitor-key` | мониторинг | только `WatchRiskEvents` и `GetDecision` |
